# Changelog

## 0.1.0 - 2026-09-01

- Add GLB and VRM 1.0 export through UniVRM 0.131.2.
- Add `MOCHIYA_materials_liltoon` material serialization.
- Add validation for the lilToon variants supported by `three-liltoon`.
- Add a Unity Editor export window and programmatic export API.
- Export metallic and smoothness control textures as linear data.
- Convert lilToon `[Gamma]` scalar properties to linear values for the web shader ABI.
